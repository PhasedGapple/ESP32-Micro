# ESP32-Micro
An ESP32-S3 which focuses on being a little long but really thin.
# Downloader Wiring
Top/Bigger Pin Header: Left to right from USB C 4PIN Receptor: GND, D+, D-, VBUS
Bottom: Replace with Pin Socket, my KiCad knowledge limitations made it show a Pin Header
# Dimensions
ESP32: 15x44 \
Downloader: 20x13
# Differences between the normal ESP32-S3 vs ESP32 Micro
- No built-in LEDs
- Very poor wifi range because the board doesnt have an antenna. You can put a metal wire on the antenna pin before soldering if you really want wifi or bluetooth.
- No VIN pins so if you want to power it thru 5v use the downloader module.
- Attachable USB C board so if you dont need USB-C then you can save the space by not using it.
